# PARA SHEYLHI

Un viaje interactivo de **Miguel Angel Borja Parra** para **Sheylhi Danitza Medrano Jara**.
Un mes más juntos · aniversario de cada primero · 1 de octubre de 2026.

## Cómo verlo ahora

Abre `index.html` en el navegador, o desde esta carpeta:

```bash
python3 -m http.server 8080
```

Luego entra a `http://localhost:8080`.

## Fotos (importante)

Pon tus imágenes en la carpeta `fotos/` con **estos nombres exactos**:

| Archivo | Qué foto |
|---|---|
| `fotos/01.JPG` | Polaroid 1 |
| `fotos/02.JPG` | Polaroid 2 |
| `fotos/03.JPG` | Polaroid 3 |
| `fotos/04.jpg` | Polaroid 4 |
| `fotos/05.JPG` | Polaroid 5 |
| `fotos/06.JPG` | Polaroid 6 |
| `fotos/07.JPG` | Foto de los dos (aparece al final) |

Sirven `.jpg`, `.png` o `.webp`. Si usas otro formato, cambia también el nombre en `js/config.js`.

Si una foto aún no está, la página igual se ve bonita: muestra un marco con una estrella.

## Personalizar textos

Todo el contenido está en `js/config.js`: carta, razones, pies de foto, nombres.

## Subirlo a GitHub Pages

1. Crea un repositorio (por ejemplo `PARA_MI_AMOR`) y sube esta carpeta.
2. En GitHub: **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.
3. El link quedará así:
   `https://TU-USUARIO.github.io/PARA_MI_AMOR/`

Ese es el enlace que le compartes a Sheylhi. Se ve mejor en el celular, en pantalla completa.
